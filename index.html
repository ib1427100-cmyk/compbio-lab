Module 1 / Proteomics

Protein Structure Predictor

DNA provides the instruction manual, but proteins are the machines that do the actual work in our bodies. Their function is entirely determined by their 3D shape. We've built an interactive tool to predict how raw biological text folds into physical shapes.

1. The Rules

Each amino acid letter naturally wants to coil into a spiral (Helix) or lay flat (Sheet). We look up these microscopic preferences.

2. The Context

Letters don't act alone. We write algorithms to analyze groups of 5 or 6 letters, because neighbors force each other into structure.

3. The Output

If the math crosses a threshold, the code snaps into a Helix (H) or a Sheet (E). If it's mathematically unstable, it stays a Coil (C).
